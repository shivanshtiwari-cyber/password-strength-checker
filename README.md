# password-strength-checker
A beginner-friendly Python project that checks password strength using length, character types, and common password detection.

## Features

- Checks password length
- Detects lowercase letters
- Detects uppercase letters
- Detects numbers
- Detects special characters
- Detects common passwords
- Gives a password strength score

## Technologies Used

- Python

## How It Works

The program analyzes the entered password based on different security characteristics and assigns a score out of 5.
